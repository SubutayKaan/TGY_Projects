# TGY_Projects
 
 Projemni başlangıç sayfasını olarak onBoarding olarak tasarladım. onBoarding sayfasında ilk iki sayfayı geçmeden "devam" butonu aktif olmuyor.
 onBoarding sayfasından sonra seçim yapabileceğimiz "kalkış yeri", "varış yeri", "zaman" seçebileceğimiz bir ekran geliyor. 
 Seçim ekranından sonra koltuk seçim ekranı bizi karşılıyor. Bu koltuk seçim ekranını pod kullanarak yaptım.
 Koltuk seçiminden sonra bilet üstüne yazılacak "isim", "soyisim" ve "tc" bilgilerinin istenildiği yeni bir ekrana geçiş yapılıyor.
 Bilgiler girildikten sonra "devam" butonuna basılırsa alt tarafta bilet detayları gösterilcektir.
